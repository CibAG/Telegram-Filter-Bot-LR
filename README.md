# Telegram Moderation Bot 1.0.0

Бот для модерации Telegram-чатов и форумных тем, ведения базы пользователей и
диалогов с пользователями через администратора или AI (OpenRouter).

## Возможности

- Мониторинг выбранных чатов и тем.
- Слова-фильтры: слово, подстрока, регулярное выражение; область — тема или весь чат.
- Удаление сообщений выбранного пользователя или всех пользователей в теме/чате.
- Исключения для отдельных пользователей.
- AI-модерация: своя текстовая инструкция для чата или темы; модель решает,
  удалить сообщение или оставить, каждое удаление приходит администратору в личку.
- Автоматическая база зарегистрированных пользователей и экспорт в CSV.
- Диалоги с пользователями в двух режимах:
  - `relay` — администратор пишет боту, пользователь получает сообщение, ответы возвращаются администратору;
  - `ai` — бот отвечает пользователю сам через OpenRouter по инструкции администратора.
- Аудит действий и статистика.
- Удаление сообщений работает и для отредактированных сообщений.
- **Всё управление — только в личке с ботом.** В группах и темах бот не показывает
  кнопок, меню и служебных сообщений: он только молча удаляет нарушения.

## Требования

- Python 3.11+ (проверено на 3.13).
- Бот создан через [@BotFather](https://t.me/BotFather).
- Бот добавлен в супергруппу и назначен администратором с правом **«Удалять сообщения»**.
- Для форумных тем в группе должны быть включены темы.

## Установка

Окружение уже подготовлено в `.venv`. Если нужно пересоздать:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

## Настройка

Скопируйте `.env.example` в `.env` (файл `.env` уже существует и не коммитится)
и заполните:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_IDS` | Числовые Telegram ID администраторов через запятую |
| `DATABASE_URL` | По умолчанию `sqlite+aiosqlite:///data/bot.db` |
| `LOG_LEVEL` | `INFO`, `DEBUG`, ... |
| `IGNORE_ADMIN_MESSAGES` | Не трогать сообщения администраторов (`true`) |
| `WARN_ON_DELETE` | Отправлять предупреждение после удаления |
| `WARN_TTL_SECONDS` | Через сколько удалять предупреждение |
| `OPENROUTER_API_KEY` | Ключ OpenRouter для AI-диалогов |
| `OPENROUTER_MODEL` | Слаг модели, например `openai/gpt-4o-mini` |
| `AI_MAX_HISTORY` | Сколько сообщений истории отправлять в модель |
| `AI_MODERATION_MODEL` | Необязательно: отдельная модель для AI-модерации (по умолчанию `OPENROUTER_MODEL`) |
| `AI_MODERATION_TIMEOUT` | Таймаут проверки сообщения в секундах (по умолчанию `20`) |
| `AI_MODERATION_ERROR_COOLDOWN` | Как часто повторять уведомление об ошибке AI в одной теме, секунды (по умолчанию `300`) |

Свой Telegram ID можно узнать у [@userinfobot](https://t.me/userinfobot).
Если `ADMIN_IDS` пуст, отправьте боту `/start` — он покажет ваш ID и попросит
добавить его в `.env`.
После изменения `.env` перезапустите бота.

## Первичная настройка в Telegram

1. Добавьте бота в супергруппу и сделайте администратором с правом удалять сообщения.
2. В @BotFather отключите приватность: `/setprivacy` → выбрать бота → `Disable`
   (иначе бот не будет видеть обычные сообщения).
3. Откройте личку с ботом и отправьте `/start` — появится панель администратора.
4. Напишите любое сообщение в группе и в каждой нужной теме: так бот запоминает
   чат и темы (Telegram не отдаёт полный список тем через API).
5. В панели откройте **«🗂 Чаты и темы»**:
   - включите чат и выберите режим «все темы» или конкретные темы;
   - при необходимости выключите отдельную тему.
6. В разделах **«🚫 Слова-фильтры»**, **«🎯 Правила»** и **«🤖 AI-модерация»**
   добавьте фильтры и правила кнопками. Ничего вводить в группу не нужно.
7. Диалоги запускаются кнопками: **«💬 Диалоги»** → **«➕ Новый диалог»**.
   Для AI выберите пользователя и отправьте задание одним сообщением.
   Команда `/dialog` тоже работает.

## Основные команды

### В личке с ботом

| Команда | Действие |
| --- | --- |
| `/start`, `/menu` | Панель администратора |
| `/users`, `/user <id\|@username>` | База пользователей |
| `/export` | CSV со всеми пользователями |
| `/dialog <id\|@username> [relay\|ai] [инструкция]` | Начать диалог |
| `/dialogs` | Активные диалоги |
| `/stopdialog [id]` | Завершить диалог |
| `/stats`, `/audit` | Статистика и журнал |
| `/cancel` | Отменить текущий ввод в панели |

### В группе/теме

Бот не принимает команды и ничего не пишет в группы. Он только удаляет сообщения,
подходящие под фильтры, правила и AI-правила, в отслеживаемых чатах и темах.

## Панель администратора

- **🗂 Чаты и темы** — список чатов, включение/выключение мониторинга,
  режим «все темы» или выбранные темы, карточки тем.
  - **✏️ Название темы** — подписать тему по её номеру;
  - **🔗 Назвать тему по ссылке** — вставить ссылку на любое сообщение из темы;
    бот сам определит номер темы (`t.me/c/<чат>/<тема>/<сообщение>`,
    `https://web.telegram.org/a/#<чат>_<тема>`), если название темы неизвестно
    (тема создана до подключения бота).
- **🚫 Слова-фильтры** — добавление фильтра (слово, подстрока, regex) для чата
  или темы и удаление существующих.
- **🎯 Правила** — удаление сообщений всех пользователей или конкретного
  пользователя в чате/теме, исключения для отдельных пользователей.
- **🤖 AI-модерация** — текстовые инструкции для чата или отдельной темы:
  список правил, добавление, изменение инструкции, включение/выключение, удаление.
- **👥 Пользователи** — база и карточки.
- **💬 Диалоги** — запуск нового диалога кнопками:
  - **🤖 AI-диалог** — выбрать пользователя и отправить задание для AI;
  - **💬 Пересылка** — выбрать пользователя и писать ему через бота;
  - **🗂 В теме чата** — бот ведёт диалог с назначенным участником прямо
    в выбранной теме форума: AI отвечает на его сообщения, либо бот публикует
    в теме текст администратора и присылает ответы собеседника в личку;
  - список активных диалогов, история, смена режима, смена задания AI,
    завершение диалога;
  - **⏸ Выключить диалог** / **▶️ Включить диалог** — пауза и возобновление
    без потери истории; **⛔ Завершить** закрывает диалог окончательно.
  - Диалог можно назначить и пользователю, который ещё не нажимал `/start`:
    он заработает, как только пользователь откроет бота (для диалога в теме
    это не требуется — достаточно, чтобы пользователь писал в теме).
- **⏹ Остановить бота** — корректно завершает процесс после подтверждения;
  данные и настройки сохраняются, запуск — снова через `start_bot.bat`.

Чаты и темы появляются в панели после сообщений в них. Если темы ещё нет в списке,
напишите в неё одно сообщение.

## Режимы диалога

- **relay** — каждое текстовое сообщение администратора боту пересылается пользователю; ответы пользователя приходят администратору в личку.
- **ai** — бот вызывает OpenRouter с инструкцией администратора и историей диалога, отвечает пользователю и присылает копию администратору.

Диалог в теме чата (`🗂 В теме чата`):

- бот реагирует только на сообщения назначенного собеседника в выбранной
  теме; сообщения остальных участников он не трогает;
- в режиме **ai** ответ публикуется прямо в теме ответом на сообщение;
- в режиме **relay** администратор пишет боту в личку, а бот публикует текст
  в теме от своего имени; ответы собеседника приходят администратору в личку;
- если тема ещё не известна боту, напишите в неё сообщение и откройте панель заново.

Для испытания можно назначить собеседником самого себя: в теме чата — в любом
режиме, в личке — только AI-режим (пересылка сообщений самому себе бессмысленна).

Ограничения:

- Бот не может написать пользователю первым, пока тот не нажал `/start`
  (это не относится к диалогу в теме).
- AI работает только с текстом. Если собеседник присылает фото, видео, голосовое
  или файл, бот **ничего не пишет в чат**: вложение приходит администратору в личку,
  и он решает, как помочь.
- Если AI не смог ответить (ошибка или пустой ответ), бот тоже молчит в чате,
  а администратору приходит уведомление с текстом собеседника.
- Один активный диалог на администратора и один на пользователя; новый заменяет предыдущий.

## AI-модерация

Раздел **«🤖 AI-модерация»** позволяет удалять сообщения не по словам, а по смыслу.
Для чата или отдельной темы задаётся текстовая инструкция, например:

> Удаляй рекламу, спам, приглашения в другие чаты и продажу услуг.

Как это работает:

1. Каждое новое текстовое сообщение или подпись к вложению уходит в OpenRouter
   вместе с инструкцией.
2. Модель отвечает строго `DELETE|причина` или `KEEP|причина`.
3. При `DELETE` бот молча удаляет сообщение, пишет запись в аудит и присылает
   администратору в личку чат/тему, автора, причину и текст сообщения.
4. При `KEEP` ничего не происходит.
5. При ошибке модели, таймауте или непонятном ответе сообщение **остаётся**
   (fail-open), а администратору приходит уведомление. Повторные ошибки в одной
   теме не спамят чаще, чем раз в `AI_MODERATION_ERROR_COOLDOWN` секунд.

Область действия:

- правило **темы** важнее правила **всего чата**;
- если для темы правило не задано, используется правило чата;
- для одной области хранится одна инструкция: повторное добавление заменяет её.

Ограничения:

- проверка занимает 1–3 секунды, сообщение может недолго повисеть в чате;
- бесплатная модель имеет лимиты: часть проверок может завершиться ошибкой,
  тогда сообщение останется;
- AI может ошибаться и удалить нормальное сообщение — все удаления приходят
  администратору с причиной;
- проверяются только текст и подписи; фото без подписи, стикеры и кружки
  не оцениваются;
- текст сообщения передаётся внешнему сервису OpenRouter;
- права «Удалять сообщения», лимит 48 часов и включённый мониторинг действуют
  так же, как для обычной модерации;
- если `OPENROUTER_API_KEY` не задан, AI-правила не работают и сообщают об ошибке
  администратору.

Порядок проверки: сначала слова-фильтры, затем правила по автору, затем AI.
Если сработал слова-фильтр или правило, AI уже не вызывается.

## Ограничения Telegram

- Удалить можно только сообщения не старше 48 часов.
- Бот не видит сообщения, отправленные до его добавления в чат.
- Без права администратора «Удалять сообщения» модерация невозможна.
- Сообщения администраторов по умолчанию не фильтруются (`IGNORE_ADMIN_MESSAGES`).
- Telegram не отдаёт полный список форумных тем: тема появляется в панели после
  первого сообщения в ней. Напишите в каждую нужную тему один раз.
- Если privacy mode включён, бот не видит обычные сообщения и не может их удалять.

## Безопасность

- `.env`, `data/`, логи и база игнорируются git.
- Ключи не выводятся в логи и сообщения.
- AI-вывод экранируется перед отправкой.
- Перед коммитом проверяйте `git diff` и `git diff --cached`.
- При утечке ключа перевыпустите его: удаление из файла не очищает историю git.
