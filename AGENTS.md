# Правила (AGENTS)

1. **Язык**: всегда общайся со мной и веди записи строго на русском языке.
2. **Границы**: работай только внутри текущей папки проекта `D:\Python\Bot`; не создавай лишних файлов.
3. **Инфраструктура** (GitHub + бесплатный PythonAnywhere, аккаунт stepbiz):
   - GitHub: `.env`, локальные БД/логи и `.venv` — строго в `.gitignore`; все секреты через `os.getenv` и `python-dotenv`.
   - Локальная БД: SQLite (до 512 МБ), путь строится строго относительно корня проекта через `pathlib.Path(__file__).resolve().parent`, добавить `PRAGMA journal_mode=WAL;` и таймаут блокировки (busy_timeout).
   - PythonAnywhere (бесплатный тариф):
     - Запуск в Bash-консоли через `polling`, с обработкой сетевых ошибок и автопереподключением.
     - Прокси из `PROXY_URL` (`http://proxy.server:3128` на сервере, локально пусто).
     - Allowlist бесплатного тарифа: внешние запросы проверять на доступность и обрабатывать ошибки доступа.
     - Все пути к файлам/БД только относительные (`pathlib.Path(__file__).parent`), актуальный `requirements.txt`.
4. **Цикл работы**: перед шагом читай `PROGRESS.md` и `.opencode/skills/python-dev/SKILL.md`; не повторяй сделанное; после правок кода проверь запуск, обнови `PROGRESS.md` и остановись для моего ручного тестирования.
